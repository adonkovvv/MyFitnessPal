# MyFitnessPal
Course project, consisting of c++ console application, having some of the functionalities of  MyFitnessPal app. Main purpose of the project is managing daily calories intake and reporting information about fitness journey.

Starting with the functionalities, all the menus, showing in the console summurise all the options that you have of what you can do with the console app. As a starting step of configuring the app to work, the text files should be present in order for the programm to run. After creating users the programm saves all the needed information in the text files, so it can work without database. Have fun with it!
